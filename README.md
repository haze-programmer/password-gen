# password-gen

 Python password generator that also saves your passwords. It is a standalone script and all you really need is python installed.
I made this program to train my Python skills.

## Commands

These commands can be easily seen by running `help` but I figured I should also place them here.

`gennew` -- Generates a new password, then asks if you want to save it (follow prompts to do so)

`delpass` -- Deletes a password (follow prompts to do so)

`viewpass` -- Views all files in the `passwords/` folder

`[ExampleFileHere.txt] (such as ExampleTwentyFiveLetterPassword.txt)` -- Views that file if it's in the `passwords/` folder

`manpass` -- Manually sets a password if the user doesn't wanna randomly set one (follow prompts to do so)

`exits` -- Exits

`help` -- Helps
